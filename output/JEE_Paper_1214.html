Q7. Numerical
A small body $A$ starts sliding off the top of a smooth sphere of radius $R = 1.5\text{ m}$. Answer Key & Detailed Step-by-Step Derivations

Question 1   Correct Answer: A
Derivation:
1. Differentiating the position coordinates with respect to time gives the velocity components: $v_x = \frac{dx}{dt} = a$ $v_y = \frac{dy}{dt} = a(1 - 2\alpha t)$ So, $\vec{v} = a\hat{i} + a(1 - 2\alpha t)\hat{j}$. 2. Differentiating velocity components gives the acceleration components: $w_x = \frac{dv_x}{dt} = 0$ $w_y = \frac{dv_y}{dt} = -2a\alpha$ So, $\vec{w} = -2a\alpha\hat{j}$. 3. The cosine of the angle $\theta$ between $\vec{v}$ and $\vec{w}$ is: $\cos\theta = \frac{\vec{v} \cdot \vec{w}}{|\vec{v}||\vec{w}|} = \frac{-2a^2\alpha(1 - 2\alpha t)}{\sqrt{a^2 + a^2(1 - 2\alpha t)^2} \cdot 2a\alpha} = \frac{-(1 - 2\alpha t)}{\sqrt{1 + (1 - 2\alpha t)^2}}$ 4. Setting $\theta = \frac{\pi}{4}$, we get $\cos\left(\frac{\pi}{4}\right) = \frac{1}{\sqrt{2}}$: $\frac{-(1 - 2\alpha t)}{\sqrt{1 + (1 - 2\alpha t)^2}} = \frac{1}{\sqrt{2}}$ Squaring both sides: $2(1 - 2\alpha t)^2 = 1 + (1 - 2\alpha t)^2 \implies (1 - 2\alpha t)^2 = 1$ Solving gives $1 - 2\alpha t = -1 \implies 2\alpha t = 2 \implies t_0 = \frac{1}{\alpha}$ (for $t_0 > 0$).
Question 2   Correct Answer: $R = \frac{a}{2\alpha} [1 + (1 - 2\alpha x/a)^2]^{3/2}$
Derivation:
1. Express $y$ in terms of $x$: Since $t = x/a$, we have $y = x\left(1 - \frac{\alpha x}{a}\right) = x - \frac{\alpha x^2}{a}$. 2. Calculate the first derivative: $\frac{dy}{dx} = 1 - \frac{2\alpha x}{a}$. 3. Calculate the second derivative: $\frac{d^2y}{dx^2} = -\frac{2\alpha}{a}$. 4. Use the formula for the radius of curvature $R = \frac{\left[1 + \left(\frac{dy}{dx}\right)^2\right]^{3/2}}{\left|\frac{d^2y}{dx^2}\right|}$. 5. Substituting the derivatives: $R = \frac{\left[1 + \left(1 - \frac{2\alpha x}{a}\right)^2\right]^{3/2}}{\frac{2\alpha}{a}} = \frac{a}{2\alpha} \left[1 + \left(1 - \frac{2\alpha x}{a}\right)^2\right]^{3/2}$.
Question 3   Correct Answer: $s = \frac{2}{3\alpha} v_0^{3/2}$
Derivation:
The acceleration is given by $a = \frac{dv}{dt} = v \frac{dv}{dx} = -\alpha \sqrt{v}$. Rearranging terms in terms of position $x$, we have $v \frac{dv}{dx} = -\alpha \sqrt{v}$, which simplifies to $\sqrt{v} \, dv = -\alpha \, dx$. Integrating both sides from the initial position $x = 0$ (where $v = v_0$) to the stopping position $x = s$ (where $v = 0$): $\int_{v_0}^0 v^{1/2} \, dv = -\alpha \int_0^s dx$. Evaluating the integral: $\left[ \frac{2}{3} v^{3/2} \right]_{v_0}^0 = -\frac{2}{3} v_0^{3/2}$. Thus, $-\frac{2}{3} v_0^{3/2} = -\alpha s \implies s = \frac{2}{3\alpha} v_0^{3/2}$.
Question 4   Correct Answer: A, B, C, D
Derivation:
1. Position vector is $\vec{r}(t) = (at - a\alpha t^2)\hat{i}$. Velocity vector is $\vec{v}(t) = \frac{d\vec{r}}{dt} = a(1 - 2\alpha t)\hat{i}$. 2. Setting $\vec{v} = 0$ gives $t_1 = \frac{1}{2\alpha}$. Thus, velocity becomes zero at $t = \frac{1}{2\alpha}$, making C correct. 3. Since motion is one-dimensional and velocity changes sign at $t_1 = \frac{1}{2\alpha}$, the particle turns back at this moment, making B correct. 4. Position at $t_1$ is $x(t_1) = a\left(\frac{1}{2\alpha}\right) - a\alpha\left(\frac{1}{2\alpha}\right)^2 = \frac{a}{4\alpha}$. Distance covered until it comes to rest is $x(t_1) - x(0) = \frac{a}{4\alpha}$, making D correct. 5. For $t > \frac{1}{2\alpha}$, distance $s = |x(t_1) - x(0)| + |x(t) - x(t_1)| = \frac{a}{4\alpha} + \left| at - a\alpha t^2 - \frac{a}{4\alpha} \right| = \frac{a}{4\alpha} + a\alpha \left(t - \frac{1}{2\alpha}\right)^2 = \frac{a}{4\alpha} \left[ 1 + 4\alpha^2 \left(t - \frac{1}{2\alpha}\right)^2 \right] = \frac{a}{4\alpha} \left[ 1 + (1 - 2\alpha t)^2 \right]$. Thus, A is also correct.
Question 5   Correct Answer: A, B, C, D
Derivation:
1. Trajectory equation: Express $t$ from $x = at \implies t = \frac{x}{a}$. Substitute into $y$: $y = a\left(\frac{x}{a}\right)\left(1 - \alpha \frac{x}{a}\right) = x - \frac{\alpha}{a}x^2$. Thus option A is correct. 2. Velocity and Acceleration: $v_x = \dot{x} = a$, $v_y = \dot{y} = a(1 - 2\alpha t)$. Acceleration components: $a_x = \ddot{x} = 0$, $a_y = \ddot{y} = -2a\alpha$. Thus $\vec{a} = -2a\alpha \hat{j}$, which is constant and directed along the negative $y$-axis. Thus option B is correct. 3. Orthogonality condition: $\vec{v} \cdot \vec{a} = v_y a_y = -2a^2\alpha(1 - 2\alpha t) = 0 \implies t = \frac{1}{2\alpha}$. Thus option C is correct. 4. Initial speed: At $t = 0$, $v_x = a$ and $v_y = a$, so initial speed $v(0) = \sqrt{a^2 + a^2} = a\sqrt{2}$. Thus option D is correct.
Question 6   Correct Answer: 3.75
Derivation:
Let total distance be $S$. 1. Time taken for the first half distance $\frac{S}{2}$ is $t_1 = \frac{S/2}{v_0} = \frac{S}{2v_0}$. 2. For the second half, let the equal time intervals be $t_2$. Then $\frac{S}{2} = v_1 t_2 + v_2 t_2 = (v_1 + v_2) t_2$, giving $t_2 = \frac{S}{2(v_1 + v_2)}$. Total time for the second half is $2t_2 = \frac{S}{v_1 + v_2}$. 3. Total time of motion $T = t_1 + 2t_2 = \frac{S}{2} \left( \frac{1}{v_0} + \frac{2}{v_1 + v_2} \right) = \frac{S (v_1 + v_2 + 2v_0)}{2 v_0 (v_1 + v_2)}$. 4. Average velocity $\langle v \rangle = \frac{S}{T} = \frac{2 v_0 (v_1 + v_2)}{v_1 + v_2 + 2v_0}$. 5. Substituting $v_0 = 3.0\text{ m/s}$, $v_1 = 2.0\text{ m/s}$, $v_2 = 8.0\text{ m/s}$: $\langle v \rangle = \frac{2 \times 3.0 \times (2.0 + 8.0)}{2.0 + 8.0 + 2 \times 3.0} = \frac{60}{16} = 3.75\text{ m/s}$.
Question 7   Correct Answer: 48
Derivation:
Let $\theta$ be the angle made by the radius vector with the vertical. By conservation of mechanical energy: $mgR(1 - \cos\theta) = \frac{1}{2}m v^2 \implies v^2 = 2gR(1 - \cos\theta)$. The equation of radial motion is $mg \cos\theta - N = \frac{m v^2}{R}$. At the moment of break-off, $N = 0$, giving $mg \cos\theta = \frac{m}{R}(2gR(1 - \cos\theta)) = 2mg(1 - \cos\theta)$. Simplifying yields $3\cos\theta = 2 \implies \cos\theta = \frac{2}{3}$. Therefore, $\theta = \arccos\left(\frac{2}{3}\right) \approx 48.19^\circ$, which rounded to the nearest integer is $48$.
